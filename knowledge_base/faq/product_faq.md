# Nexora Technologies Product & Hardware FAQ

## What router models does Nexora Technologies offer?
1. **Nexora Technologies Archer Pro (Wi-Fi 6)**: Dual-band Gigabit router suitable for high-speed fiber plans up to 1 Gbps.
2. **Nexora Technologies Mesh Nova**: Whole-home mesh system covering up to 4,000 sq ft with seamless roaming.
3. **Nexora Technologies StreamBox**: High-performance smart gateway with integrated firewall and parental controls.

## What is the maximum number of connected devices supported?
- Archer Pro supports up to 64 concurrent devices.
- Mesh Nova 3-pack supports up to 120 concurrent devices without packet drop.

## Does Nexora Technologies provide free installation?
Yes, all smart router purchases include complimentary remote onboarding and optional technician doorstep setup in eligible metropolitan zones.
