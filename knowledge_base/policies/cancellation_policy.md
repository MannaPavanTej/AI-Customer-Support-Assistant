# Nexora Technologies Cancellation Policy

## Order Cancellation
- **Pre-Dispatch**: Customers can cancel hardware orders anytime before the package is handed over to the courier partner directly via the Nexora Technologies Mobile App or by contacting customer support. Full refunds are processed automatically.
- **Post-Dispatch**: If an order has already been dispatched, cancellation is not possible. The customer should decline delivery upon arrival, and a refund will be issued once the package returns to our facility.

## Subscription Cancellation
- Cloud security and mesh monitoring subscriptions can be cancelled at any time from the Nexora Technologies account dashboard.
- Cancellation takes effect at the end of the current billing cycle. No prorated refunds are issued for partial months.
